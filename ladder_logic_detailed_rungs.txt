SECTION 2: IDLE STATE LOGIC (Rungs 020-029)
===============================================================================

---[ RUNG 020 ]----------------------------------------------------------------
Purpose: Wait for start button in IDLE state
Logic: When start pressed and in IDLE, transition to PLAYBACK

  ──┤iGameState = STATE_IDLE├──┤bStartPressed├──[MOV STATE_PLAYBACK iGameState]──
                                                  [MOV 0 iSequenceLength]
                                                  [MOV 1 iLevel]
                                                  [MOV 0 iPlaybackIndex]
                                                  [MOV 0 iInputIndex]
                                                  ( bGameActive )

---[ RUNG 021 ]----------------------------------------------------------------
Purpose: Reset all LEDs in IDLE state
Logic: Turn off all outputs when idle

  ──┤iGameState = STATE_IDLE├──( /doLedYellow )──
                               ( /doLedBlue )
                               ( /doLedRed )

Note: ( / ) means reset/turn off the coil

---[ RUNG 022 ]----------------------------------------------------------------
Purpose: Initialize random seed with more entropy (optional enhancement)
Logic: Use system clock or timer to add randomness

  ──┤iGameState = STATE_IDLE├──┤bStartPressed├──[COMPUTE]──
                                                  iRandomSeed := iRandomSeed + DINT#(iLevel * 17)

Note: This adds some variability based on timing

SECTION 3: PLAYBACK STATE LOGIC (Rungs 030-049)
===============================================================================

---[ RUNG 030 ]----------------------------------------------------------------
Purpose: Generate new sequence step at start of playback
Logic: When entering PLAYBACK and index is 0, add one button to sequence

  ──┤iGameState = STATE_PLAYBACK├──┤iPlaybackIndex = 0├──┤/bPlaybackActive├──[COMPUTE]──
                                                                              ( bPlaybackActive )

COMPUTE block contents:
  iRandomSeed := (iRandomSeed * RNG_MULTIPLIER + RNG_INCREMENT) MOD RNG_MODULUS;
  iCurrentButton := (iRandomSeed MOD NUM_BUTTONS) + 1;
  aiSequence[iSequenceLength] := iCurrentButton;
  iSequenceLength := iSequenceLength + 1;

Note: This implements a Linear Congruential Generator (LCG)

---[ RUNG 031 ]----------------------------------------------------------------
Purpose: Load current sequence button for playback
Logic: Get the button code from the sequence array

  ──┤iGameState = STATE_PLAYBACK├──┤bPlaybackActive├──┤iPlaybackIndex < iSequenceLength├──
    ┤/tFlashTimer.Q├──[MOV aiSequence[iPlaybackIndex] iCurrentButton]──

---[ RUNG 032 ]----------------------------------------------------------------
Purpose: Start flash timer when ready to show next button
Logic: Begin the LED flash cycle

  ──┤iGameState = STATE_PLAYBACK├──┤bPlaybackActive├──┤iPlaybackIndex < iSequenceLength├──
    ┤/tFlashTimer.Q├──┤/tGapTimer.Q├──[TON tFlashTimer]──
                                      ( bFlashOn )

TON parameters:
  IN := TRUE (condition met)
  PT := tFlashTime (500ms)

---[ RUNG 033 ]----------------------------------------------------------------
Purpose: Hold flash on during timer
Logic: Keep bFlashOn active while timer running

  ──┤tFlashTimer.Q├──( bFlashOn )──

---[ RUNG 034 ]----------------------------------------------------------------
Purpose: End flash when timer done
Logic: Reset flash flag and start gap timer

  ──┤tFlashTimer.DN├──[RESET tFlashTimer]──
                      [TON tGapTimer]
                      ( /bFlashOn )

TON parameters:
  IN := TRUE
  PT := tGapTime (200ms)

---[ RUNG 035 ]----------------------------------------------------------------
Purpose: Advance to next sequence position after gap
Logic: Increment playback index

  ──┤tGapTimer.DN├──[ADD iPlaybackIndex 1 iPlaybackIndex]──
                    [RESET tGapTimer]

---[ RUNG 036 ]----------------------------------------------------------------
Purpose: Check if playback complete
Logic: When all sequence shown, move to input state

  ──┤iGameState = STATE_PLAYBACK├──┤iPlaybackIndex >= iSequenceLength├──
    [MOV STATE_WAIT_INPUT iGameState]──
    [MOV 0 iInputIndex]
    [MOV 0 iPlayerInput]
    ( /bPlaybackActive )
    [TON tInputTimeout]

TON parameters:
  IN := TRUE
  PT := tInputTimeoutVal (3000ms)

---[ RUNG 050 ]----------------------------------------------------------------

---[ RUNG 051 ]----------------------------------------------------------------

  ──┤iGameState = STATE_WAIT_INPUT├──┤bButtonB_Pressed├──┤iPlayerInput = 0├──
    [MOV BTN_BLUE iPlayerInput]──

---[ RUNG 052 ]----------------------------------------------------------------
Purpose: Capture Red button press during input phase

  ──┤iGameState = STATE_WAIT_INPUT├──┤bButtonR_Pressed├──┤iPlayerInput = 0├──
    [MOV BTN_RED iPlayerInput]──

---[ RUNG 053 ]----------------------------------------------------------------
Purpose: Validate player input - CORRECT path
Logic: Check if input matches sequence

  ──┤iGameState = STATE_WAIT_INPUT├──┤iPlayerInput > 0├──
    ┤iPlayerInput = aiSequence[iInputIndex]├──[ADD iInputIndex 1 iInputIndex]──
                                              [MOV 0 iPlayerInput]
                                              [RESET tInputTimeout]
                                              ( bCorrectInput )

---[ RUNG 054 ]----------------------------------------------------------------
Purpose: Restart input timeout after correct input
Logic: Give player time for next button

  ──┤bCorrectInput├──[TON tInputTimeout]──
                     ( /bCorrectInput )

TON parameters:
  IN := TRUE
  PT := tInputTimeoutVal (3000ms)

---[ RUNG 055 ]----------------------------------------------------------------
Purpose: Validate player input - WRONG path
Logic: Input doesn't match sequence

  ──┤iGameState = STATE_WAIT_INPUT├──┤iPlayerInput > 0├──
    ┤iPlayerInput <> aiSequence[iInputIndex]├──[MOV STATE_GAME_OVER iGameState]──
                                               [MOV 0 iPlayerInput]
                                               ( bWrongInput )
                                               ( /bGameActive )
                                               [RESET tInputTimeout]

---[ RUNG 056 ]----------------------------------------------------------------
Purpose: Handle input timeout
Logic: Player took too long to press button

  ──┤iGameState = STATE_WAIT_INPUT├──┤tInputTimeout.DN├──
    [MOV STATE_GAME_OVER iGameState]──
    ( bTimeout )
    ( /bGameActive )
    [RESET tInputTimeout]

---[ RUNG 057 ]----------------------------------------------------------------
Purpose: Check if player completed sequence
Logic: Input index reached sequence length

  ──┤iGameState = STATE_WAIT_INPUT├──┤iInputIndex >= iSequenceLength├──
    [MOV STATE_PLAYBACK iGameState]──
    [MOV 0 iPlaybackIndex]
    [ADD iLevel 1 iLevel]
    ( bSequenceComplete )
    ( /bPlaybackActive )

---[ RUNG 058 ]----------------------------------------------------------------
Purpose: Reset sequence complete flag
Logic: Clear on next scan

  ──┤bSequenceComplete├──( /bSequenceComplete )──

Note: This rung runs after the transition, clearing the flag

For complex calculations, ST (Structured Text) may be clearer:

---[ Random Number Generation (Rung 030 equivalent) ]-------------------------

IF iGameState = STATE_PLAYBACK 
   AND iPlaybackIndex = 0 
   AND NOT bPlaybackActive THEN
   
    (* Linear Congruential Generator *)
    iRandomSeed := (iRandomSeed * RNG_MULTIPLIER + RNG_INCREMENT) MOD RNG_MODULUS;
    
    (* Map to button range 1-3 *)
    iCurrentButton := (iRandomSeed MOD NUM_BUTTONS) + 1;
    
    (* Add to sequence *)
    aiSequence[iSequenceLength] := iCurrentButton;
    iSequenceLength := iSequenceLength + 1;
    
    (* Mark playback as started *)
    bPlaybackActive := TRUE;
END_IF;

===============================================================================
COMMON ISSUES & SOLUTIONS
===============================================================================

ISSUE 1: LEDs don't flash correctly
- Check timer reset logic (must reset before next use)
- Verify flash/gap timing values
- Ensure only one LED output per scan cycle

ISSUE 2: Button presses not detected
- Verify edge detection logic (rising edge only)
- Check input filtering settings (debounce)
- Monitor bButtonX_Pressed flags in online mode

ISSUE 3: Random sequence not random
- Seed with variable value (time, counter, etc.)
- Verify MOD operation works correctly
- Test with different seed values

ISSUE 4: Game state stuck
- Check all transition conditions
- Verify timer done bits (.DN)
- Ensure no conflicting state assignments

ISSUE 5: Input timeout too short/long
- Adjust tInputTimeoutVal constant
- Consider player skill level
- Add difficulty settings
