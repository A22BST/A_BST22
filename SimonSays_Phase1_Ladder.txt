I/O ALLOCATION TABLE:
----------------------
Input Module (NX-ID4442):
- DI1 (0.1): Yellow Button Contact
- DI3 (0.3): Blue Button Contact  
- DI5 (0.5): Red Button Contact

Output Module (NX-OD4256):
- DO0 (0.0): Red LED
- DO1 (0.1): Blue LED
- DO2 (0.2): Yellow LED

================================================================================
GLOBAL VARIABLES TO DEFINE:
================================================================================

Name                    Data Type    Initial Value    Comment
--------------------------------------------------------------------------------
GameState              INT          0                0=Idle, 1=NewGame, 2=ShowSeq, 3=WaitInput, 4=Check, 5=GameOver, 6=Victory
GameSequence           ARRAY[0..49] OF INT          Stores button sequence
CurrentLevel           INT          0                Current sequence length
SequenceIndex          INT          0                Position in sequence display
PlayerInputIndex       INT          0                Position in player input
MaxLevel               INT          10               Maximum sequence length
LastButtonPressed      INT          0                Last button: 1=Y, 2=B, 3=R
RandomSeed             DINT         12345            Random number seed
RandomValue            INT          0                Generated random value
StartGame              BOOL         FALSE            Start game trigger
ShowingSequence        BOOL         FALSE            Currently showing sequence
WaitingForInput        BOOL         FALSE            Waiting for player input
InputCorrect           BOOL         TRUE             Player input is correct

TIMERS:
TMR_Flash              TON          T#500MS          LED flash duration
TMR_Gap                TON          T#300MS          Gap between flashes
TMR_InputTimeout       TON          T#5S             Player input timeout
TMR_StartDelay         TON          T#2S             Game start delay
TMR_Celebration        TON          T#100MS          Victory animation timer

================================================================================
FUNCTION BLOCKS TO CREATE:
================================================================================

1. RANDOM Number Generator Function Block:
   - Input: Seed (DINT)
   - Output: RandomValue (INT, 1-3)
   - Formula: Linear Congruential Generator
   
2. CELEBRATION_PATTERN Function Block:
   - Cycles through LEDs in sequence
   - Creates victory animation

================================================================================
IMPLEMENTATION NOTES:
================================================================================

1. Timer Configuration:
   - All timers should be configured as TON (Timer On Delay)
   - Adjust timing values based on desired difficulty

2. Array Handling:
   - GameSequence array stores values 1-3 (Yellow, Blue, Red)
   - Maximum sequence length is configurable via MaxLevel

3. Edge Detection:
   - Use P (positive edge) contacts for button press detection
   - Prevents multiple triggers from held buttons

4. LED Control:
   - LEDs light when buttons are pressed during player input
   - LEDs flash in sequence during demonstration
   - All LEDs flash at game start
   - Red LED flashes on game over
   - Rotating pattern on victory

5. State Machine:
   - Clean transitions between states
   - No overlapping state conditions
   - Reset conditions clearly defined
